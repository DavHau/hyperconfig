# hyperconfig

Dave's clan-based NixOS fleet. Before exploring, read
`skills/hyperconfig-map/SKILL.md` (where things live, `nix eval`
one-liners, recipes; grep its `references/map-*.md` for machines,
modules, options and generators). After adding, moving or renaming a
module, run `nix run .#repo-map` and commit the regenerated maps.
